# எழுது (eluthu): தமிழ் தொடு-தட்டச்சுப் (Touch typing) பயிற்சி

**▶ [இப்போதே தொடங்குங்கள்](https://ennumezuththum.github.io/eluthu/)** — முற்றிலும் இலவசம், உங்களது கணினி உலாவியிலேயே (Browser) நேரடியாக இயங்கும், மென்பொருள்கள் எதுவும் தரவிறக்க வேண்டியதில்லை.

![எழுது — தமிழ் தட்டச்சுப் பயிற்சி திரை](assets/preview.png)

**எழுது (eluthu)** என்பது **தமிழ் 99** விசைப்பலகை அமைப்பில் தொடு-தட்டச்சு பழக உதவும் ஒரு இலவச மற்றும் திறந்த மூல (Open-Source) தமிழ் தட்டச்சுப் பயிற்சித் தளமாகும்.

2015-ஆம் ஆண்டில், ஒரு தொடு-தட்டச்சுப் பயிற்சித் தளம் எனது ஆங்கிலத் தட்டச்சுத் திறனைப் பெருமளவில் மாற்றியமைத்தது. விசைகளைத் தேடித் தேடி நிமிடத்துக்கு 20 சொற்கள் தட்டச்சு செய்துகொண்டிருந்த நான், [TypingClub](https://www.typingclub.com/) மூலம், விசைப்பலகையைப் பார்க்காமலேயே பத்து விரல்களாலும் நிமிடத்துக்கு 80-க்கும் மேற்பட்ட சொற்களை இலகுவாகத் தட்டச்சு செய்யப் பழகினேன்.

தமிழுக்கும் அதுபோன்ற ஒரு பயிற்சித் தளம் இல்லாததைக் கண்டபோதே, **எழுது** செயலியை உருவாக்கத் தீர்மானித்தேன். **எழுது**வின் முக்கிய அம்சங்கள், ஏன் தமிழ் 99-ஐக் கற்பிக்கிறது, தொடு-தட்டச்சு ஏன் கற்க வேண்டும் என்பவற்றைக் கீழே காணலாம்.

## முக்கிய அம்சங்கள்

- **படிப்படியான பாடங்கள்:** உங்கள் விரல்களுக்குத் தானாகவே பழகும் வகையில் (Muscle memory) கட்டம் கட்டமாக வடிவமைக்கப்பட்ட பயிற்சிகள்.
- **மூன்று நிலைகள்:** **எழுது**வில் மூன்று நிலைகள் உள்ளன: **ஆரம்ப நிலை**, **இடைநிலை**, மற்றும் **உயர் நிலை**.
  - **ஆரம்ப நிலைப்** பாடங்களில் புள்ளி (்), உயிரெழுத்துகள் (உ+ம் அ) மற்றும் அகரமேறிய உயிர்மெய் எழுத்துகளையும் (உ+ம் க) தட்டச்சு செய்யப் பழகுவீர்கள்.
  - **இடைநிலைப்** பாடங்களில் மெய் எழுத்துகள் (உ+ம் க்) மற்றும் அகரமேறாத உயிர்மெய் எழுத்துகளையும் (உ+ம் கா) எவ்வாறு தட்டச்சு செய்வது என்பதைப் பழகுவீர்கள்.
  - **உயர் நிலைப்** பாடங்களில், வசனங்கள் மற்றும் பந்திகளைப் பயிற்சி செய்வீர்கள்.
- **விரல்-இட வழிகாட்டல்:** அகரவரிசையில் இல்லாமல், விரல்களின் இயல்பான நிலைக்கு ஏற்ப எழுத்துக்கள் அறிமுகப்படுத்தப்படுகின்றன. (நீங்கள் முதன்முதலில் படிக்கும் இரு எழுத்துக்கள்: `J` விசையிலுள்ள **ப** மற்றும் `F` விசையிலுள்ள **்** புள்ளி ஆகும்.)
- **திரையில் தெரியும் தட்டச்சு வழிகாட்டி:** **எழுது**-இன் நிற விசைப்பலகை ஒவ்வொரு விசையையும் எந்த விரலால் அழுத்த வேண்டும் என்பதைக் காட்டும்; அடுத்து அழுத்த வேண்டிய விசை வெள்ளை நிறத்தில் தெரியும்; கைகளின் படமும் எந்த விரலைப் பயன்படுத்த வேண்டும் எனக் காட்டும். குழப்பங்களைத் தவிர்க்க, நீங்கள் பழகும் அல்லது பழகிய எழுத்துக்கள் மட்டுமே திரையில் தெரியும்.
- **இலக்கண ஒருங்கிணைப்பு:** அடிப்படை உயிர் எழுத்துக்களுக்குப் பிறகு, மெய் எழுத்துக்கள் தமிழ் 99-இன் இயல்பான இலக்கண ஓட்டத்தோடு அறிமுகப்படுத்தப்படுகின்றன.
- **தொடர்பாடல் தகவல்கள்:** பாடங்களுக்கு இடையே தோன்றும் வழிகாட்டுதல் திரைகள் உங்கள் கற்றல் பயணத்தில் துணைநிற்கும்.
- **அறிமுகம், பயிற்சி & மதிப்பாய்வு:** ஒவ்வொரு விசைக்கும் இரண்டு பிரிவுகள் உள்ளன: அறிமுகம்  மற்றும் பயிற்சி. இடையிடையே உங்கள் தட்டச்சை மதிப்பாய்வு செய்வீர்கள். அறிமுகத்தில் பிழையான விசையை அழுத்தினால் cursor நகராது. பயிற்சியில் 90%+ துல்லியமும் மதிப்பாய்வில் 80%+ துல்லியமும் எடுக்க வேண்டும்.
- **பாவனையில் உள்ள தமிழ் சொற்கள்:** நீங்கள் கற்ற எழுத்துகளைக் கொண்டு மட்டுமே உருவாக்கப்பட்ட, பாவனையில் உள்ள தமிழ் சொற்களும் சொற்றொடர்களும் பயன்படுத்தப்படுகின்றன.
- **சுய முன்னேற்றச் சேமிப்பு:** ஒவ்வொரு பாடத்திலும் உங்களது முன்னேற்றம் உங்களது கணினி உலாவியிலேயே தானாகச் சேமிக்கப்பட்டு, வரைபடங்களாகக் காட்டப்படும்.
- **முன்னேற்றக் கண்காணிப்பு:** தொடர் நாள் வரைபடம், சாதனைப் பதக்கங்கள், பாட நட்சத்திர மதிப்பீடுகள் — [உங்கள் முன்னேற்றத்தைக் கண்காணியுங்கள்](#உங்கள்-முன்னேற்றத்தைக்-கண்காணியுங்கள்) பகுதியைப் பார்க்கவும்.
- **தமிழ் 99 எழுதும் பகுதி:** தடையின்றி எழுதுவதற்கான, தனித்து இயங்கும் இலகுவான தமிழ் சொல் செயலி — [தமிழ் 99 எழுதும் பகுதி](#தமிழ்-99-எழுதும்-பகுதி) பகுதியைப் பார்க்கவும்.

> **குறிப்பு:** கிரந்த எழுத்துக்களும் (ஸ, ஷ, ஜ, ஹ, க்ஷ) எண்களும் இன்னும் சேர்க்கப்படவில்லை. அவை [எதிர்காலத் திட்டங்களில்](#எதிர்காலத்-திட்டங்கள்-roadmap) உள்ளன.

## ஏன் தமிழ் 99 (Tamil 99)?

பல தமிழ் விசைப்பலகை அமைப்புகள் (Keyboard layouts) பயன்பாட்டில் உள்ளன. அவற்றுள் **தமிழ் 99 (Tamil 99)**, **பாமினி (Bamini)**, மற்றும் **அஞ்சல் (Anjal)** ஆகியன மிகவும் பிரபலமான தமிழ் விசைப்பலகை அமைப்புகள் ஆகும்.

- **அஞ்சல்** என்பது "பேசும் ஒலி வடிவிலேயே தட்டச்சு செய்யும்" (Type as you speak) முறையாகும் (உ+ம், **கா** = k + A [Key K + Shift + Key A]). இது தொடக்க நிலையில் தட்டச்சு பழகுபவர்களுக்கு எளிதாக இருக்கும்.

- **பாமினி** பாரம்பரிய தமிழ் தட்டச்சுப் பொறிகளின் (Typewriter) முறையை ஒட்டி அமைந்தது (உ+ம், **கா** = க [Key i] + ா [Key m]).

- **தமிழ் 99** மெய்-உயிர் (உ+ம், **கா** = க [Key H] + ஆ [Key Q]) என்ற தமிழ் இலக்கண முறைமையைப் பயன்படுத்தி தட்டச்சு செய்ய வழிசெய்கிறது. இது மூன்று வடிவமைப்புக் கோட்பாடுகளைக் கொண்டது:

   1. **குறைந்த விரல் நகர்வு:** தமிழ் மொழியில் எழுத்துக்கள் எவ்வளவு அடிக்கடி பயன்படுகின்றன என்பதன் அடிப்படையில் விசைகள் அமைக்கப்பட்டுள்ளதால், விரல்களின் நகர்வுத் தூரம் குறைக்கப்படுகிறது.
   2. **குறைந்த விசை அழுத்தங்கள்:** ஒரு மெய்யெழுத்தைத் தொடர்ந்து அதே மெய்யெழுத்தின் உயிர்மெய் வடிவம் வரும் சொற்களும் (உ+ம்: அ**ம்மம்மா**), அதேபோல, ஒரு மெல்லின மெய்யெழுத்தைத் தொடர்ந்து அதன் இனமான வல்லின உயிர்மெய் வடிவம் வரும் சொற்களும் (உ+ம்: த**ம்பி**) தமிழில் அதிகம். இவ்வாறான சொற்களில் மெய்யெழுத்துகளுக்கு நீங்கள் புள்ளியிட வேண்டியதில்லை — **தமிழ் 99** தானாகவே புள்ளியை இடும் (உ+ம்: **வணக்கம்** என்பதில் **க்க**).
   3. **குறைவான `Shift` பயன்பாடு:** விரல்கள் உளையாமல் இருக்க **தமிழ் 99**-இல் `Shift` பயன்பாடு மிகக் குறைவு. வடமொழி (Grantha) & அரிதான குறியீடுகளுக்கு மட்டுமே `Shift` தேவைப்படும்.

தமிழ் 99, 1999-ஆம் ஆண்டில் அங்கீகரிக்கப்பட்ட, தமிழ்நாடு அரசின் அதிகாரபூர்வ தரநிலை விசைப்பலகை அமைப்பும் ஆகும் ([மூலங்களும் மேற்கோள்களும்](#மூலங்களும்-மேற்கோள்களும்) பகுதியைப் பார்க்கவும்).

### அமைப்புகளின் ஒப்பீடு

**வணக்கம்** என்ற சொல்லைத் தட்டச்சு செய்ய:

| விசைப்பலகை அமைப்பு | விசை அழுத்தங்கள் (Keystrokes) | தனித்துவமான விசைகள் | `Shift` விசை தேவையா? |
| :--- | :---: | :---: | :---: |
| **தமிழ் 99** | **6** | **5** | **இல்லை** |
| பாமினி (Bamini) | 7 | 5 | இல்லை |
| அஞ்சல் (Anjal) | 8 | 6 | ஆம் |

குறைந்த விசை அழுத்தங்களுடன் தமிழ் 99 தெளிவாக முன்னிலையில் உள்ளது. **தமிழ் 99** விசைப்பலகை தமிழ் இலக்கண விதிகளை அடிப்படையாகக் கொண்டு வடிவமைக்கப்பட்டுள்ளதால், இயல்பான மற்றும் வேகமான தொடு-தட்டச்சுப் பயிற்சிக்கு அதுவே பொதுவாக விரும்பப்படுகிறது.

## ஏன் தொடு-தட்டச்சு கற்க வேண்டும்?

### விசைப்பலகையில் ஏன் தட்டச்சு செய்ய வேண்டும்?

திறன்பேசிகளும் (smartphones) குரல் வழித் தட்டச்சு (Voice-to-Text) செயலிகளும் நிறைந்த இந்தக் காலத்தில், விசைப்பலகை மூலம் தட்டச்சு செய்வது இன்னமும் அவசியமா என்று நீங்கள் யோசிக்கலாம்.

சின்னச் சின்னக் குறிப்புகளைக் குரல் வழியில் சொல்வது இலகுவாக இருந்தாலும், தெளிவான ஒரு கட்டுரையை எழுதவோ, திருத்தவோ, மீளமைக்கவோ கைமுறையான திருத்தங்கள் (Manual editing) கட்டாயம் தேவை. நீங்கள் தொடர்ச்சியாக எழுதுபவர் என்றால், விசைப்பலகையில் திறம்படத் தட்டச்சு செய்யும் திறன் மிகவும் அவசியமானது.

### தொடு-தட்டச்சு என்றால் என்ன?

தொடு-தட்டச்சு என்பது விசைகளைப் பார்க்காமல், பத்து விரல்களையும் பயன்படுத்திக் கணினி விசைப்பலகையில் தட்டச்சு செய்யும் திறன் ஆகும்.

| | தொடு-தட்டச்சு | தேடித் தட்டுதல் (Hunt-and-peck) |
| :--- | :--- | :--- |
| **கைகள்** | விரல்கள், மணிக்கட்டுகள், கைகள் தளர்வான நிலையில் இருக்கும். வேலைப்பளு பத்து விரல்களுக்கும் பகிரப்படுவதால் நகர்வு குறைவு; உளைவு குறைகிறது. | கைகளை அந்தரத்தில் தூக்கியபடி, கரங்கள் விசைப்பலகை முழுவதும் நகர்வதால் மூட்டுகளுக்குத் தேவையற்ற அழுத்தம் ஏற்படுகிறது. |

### தொடு-தட்டச்சின் நன்மைகள்

1. **சிறந்த உடல் நிலை:** விரல்கள், மணிக்கட்டுகள், கரங்கள், கழுத்து, முதுகு, கண்கள் ஆகியவற்றில் அழுத்தமும் சோர்வும் குறைவு.
2. **சிறந்த ஆக்கங்கள்:** உங்கள் கவனம் விசைகளில் அல்லாமல் எண்ணங்களிலேயே இருப்பதால், நீங்கள் சுலபமாக எழுதலாம்.
3. **அதிக வேகம்:** தசை நினைவாற்றல் பழகிய பின், விரல்கள் விசைகளை மிக வேகமாக அழுத்துகின்றன.
4. **அதிக துல்லியம்:** தசை நினைவாற்றலால் எழுத்துப்பிழைகள் குறைவு; பார்வை திரையில் இருப்பதால் தவறுகளை உடனே கண்டறிவதோடு உடனே அவற்றைத் திருத்தலாம்.
5. **அணுகல்தன்மை (Accessibility):** பார்வைக் குறைபாடுள்ளவர்களும் விசைப்பலகையைப் பார்க்காமலேயே சரளமாகத் தட்டச்சு செய்ய தொடு-தட்டச்சு உதவுகிறது.

### கற்க என்ன தேவை?

* **தொடர் பயிற்சி:** தினமும் 15 நிமிடம் தொடர் பயிற்சி செய்தால், மூளை விரல்களுக்குத் தானாகக் கட்டளையிடப் (Muscle Memory) பழகிவிடும். ஆறு வாரங்களுக்கு இவ்வாறு பயிற்சி செய்யுமாறு பரிந்துரைக்கிறேன்; ஆனால் முன்னேற்றம் ஆளுக்கு ஆள் வேறுபடும்.
* **பொறுமை:** விரல்கள் தடுமாறினால் கவலைப்படாதீர்கள்! அதிவேகம் ஒரே இரவில் வந்துவிடாது. தொடக்கத்தில் உங்கள் தட்டச்சு வேகம் தற்காலிகமாகக் குறையும் — ஊக்கத்துடனும் பொறுமையுடனும் இருங்கள்.
* **பார்வை திரையில்:** தொடு-தட்டச்சின் ஒரே ஒரு விதி: **எக்காரணத்தைக் கொண்டும் உங்கள் விசைப்பலகையைப் பார்க்கக் கூடாது!**
* **பழைய பழக்கங்களை விடுதல்:** பழைய தேடித் தட்டும் விரல் அசைவுகளை மறக்கத் தயாராக இருங்கள்.
* **வேகத்தை விடத் துல்லியம்:** துல்லியத்தில் (accuracy) கவனம் செலுத்தவும், பழகப் பழக வேகம் தானாகவே கூடும்!
* **சிறப்புக் கருவிகள் தேவையில்லை:** நீங்கள் தமிழ் விசைப்பலகையை (keyboard) வாங்கவோ, தமிழ் எழுத்துகளை விசைகளில் (key) ஒட்டவோ தேவையில்லை. உங்களிடம் இருக்கும் **சாதாரண QWERTY விசைப்பலகையே போதுமானது**. **எழுது**-வுக்கு வெளியே தமிழில் தட்டச்சு செய்ய, உங்கள் இயங்குதளத்தில் (OS) தமிழ் 99 விசைப்பலகையை இயக்க வேண்டும். **தமிழ் 99** விசைப்பலகையை எந்தவொரு இயங்குதளத்திலும் மிக எளிதாகச் செயல்பட வைக்க முடியும். அதை எவ்வாறு செயல்படுத்துவது என்பதற்கான வழிகாட்டுதல்கள் தேவைப்பட்டால், [கருத்துப் படிவம்](https://forms.gle/uwwtEWPmU6NVf6QaA) வழியே எங்களை அணுகுங்கள்.

## தமிழ் 99 எழுதும் பகுதி

பாடத் திட்டத்திலிருந்து முற்றிலும் தனித்த ஒரு எழுத்துப் பகுதி — கடிதங்கள், குறிப்புகள், பாடசாலைச் செய்தி மடல்கள் என எதையும் நீங்கள் எழுதலாம்.

- **தமிழ் 99-ல் தட்டச்சு செய்யுங்கள்**, இரு வழி பிரதி/ஒட்டு (Copy/Paste) வசதியுடன் (பட்டன் அல்லது Ctrl+V/Cmd+V மூலம்) உரையை உள்ளேயும் வெளியேயும் நகர்த்தலாம்.
- **உண்மையான திருத்தம்** — அம்பு விசைகள் (Left/Right, Home/End) மூலம் நகரலாம்; இறுதியில் மட்டுமல்லாமல் எங்கு வேண்டுமானாலும் உரையைச் செருகலாம் அல்லது நீக்கலாம்.
- **தானியங்கு சேமிப்பு** — நீங்கள் தட்டச்சு செய்வதை நிறுத்தி ஒரு விநாடியில் உங்கள் வரைவு தானாகச் சேமிக்கப்படும், சிறிய "சேமிக்கப்பட்டது ✓" குறிப்புடன். அடுத்த முறை பக்கத்தைத் திறக்கும்போது (Hard Refresh செய்த பின்னும்) அது தானாக மீட்டெடுக்கப்படும்.

இங்கு நீங்கள் எழுதுவது எதுவும் உங்கள் தொடர் நாட்கள், பதக்கங்கள், அல்லது பாட நட்சத்திரங்களில் கணக்கிடப்படாது.

## தனிப்பாதுகாப்பு & நம்பகத்தன்மை (Privacy & Security)

**எழுது** முற்றிலும் உங்களது தனிப்பாதுகாப்பை உறுதி செய்யும் வகையில் உருவாக்கப்பட்டுள்ளது:

- **தரவுகள் எதுவும் வெளியேறாது:** நீங்கள் தட்டச்சு செய்வது எதுவும் உங்களது கணினியை விட்டு வெளியே போகாது. அனைத்துச் செயல்பாடுகளும் உங்களது கணினி உலாவியிலேயே நடைபெறுகின்றன.
- **கணக்குகள் எதுவும் தேவையில்லை:** பதிவு செய்வதோ, உள்நுழைவதோ, உங்களது தனிப்பட்ட விபரங்களைக் கொடுப்பதோ தேவையில்லை.

## உருவாக்குநர் குறிப்புகள் (Developer Notes)

### உங்கள் கணினியில் இயக்குதல்

1. களஞ்சியத்தை (repository) நகலெடுங்கள்:
   ```bash
   git clone https://github.com/eNNumEzuththum/eluthu.git
   cd eluthu
   ```
2. ஒரு உள்ளூர் சேவையகத்தை (local server) தொடங்குங்கள்:
   ```bash
   python3 -m http.server 8080
   ```
3. உங்கள் உலாவியில் http://localhost:8080 ஐத் திறவுங்கள்.

### பாடங்களை மீள் உருவாக்குதல்

பாடங்கள் கைமுறையாகத் திருத்தப்படும் இரண்டு மூலங்களிலிருந்து உருவாக்கப்படுகின்றன: `lesson_plan.json` (பாட வரையறைகள்) மற்றும் `words.txt` (அடிக்கடி பயன்படும் தமிழ் சொற்கள்).

```bash
python3 add_words_to_lesson.py   # lesson_plan.json + words.txt → lesson_words.json
python3 generate_lessons.py      # lesson_words.json → data/lessons.json + data/exercises/
```

### குறியீட்டு அமைப்பு (Code Structure)

```text
.
├── index.html                # Main entry point for the web application
├── tamil99-writer.html       # Standalone Tamil99 word processor — separate from lesson progress
├── css/
│   └── style.css             # Application styles
├── js/
│   ├── tamil99.js            # Tamil 99 layout rules and character mapping
│   ├── combination.js        # Keystroke stream engine for combination typing
│   ├── typing.js             # Standard character-by-character typing engine
│   ├── lessons.js            # Lesson loader and progression controller
│   ├── app.js                # Core application orchestrator
│   └── version.js            # Application versioning tracker
├── assets/
│   ├── keyboard.svg          # Keyboard layout diagram with finger guides
│   └── keyboard_all_keys.svg # Dual-labelled keyboard diagram (Tamil + English)
├── data/
│   ├── lessons.json          # Lesson manifest (ordering, metadata, exercise lists)
│   ├── tamil99-keymap.json   # QWERTY to Tamil 99 key bindings
│   └── exercises/
│       └── XX-XX.json        # Individual exercise JSON data files
├── lesson_plan.json          # Minimal hand-edited lesson definitions
├── words.txt                 # Frequently used Tamil word database
├── add_words_to_lesson.py    # Reads lesson_plan.json + words.txt → lesson_words.json
├── lesson_words.json         # Generated: lesson metadata + matched words per lesson
├── generate_lessons.py       # Reads lesson_words.json → data/lessons.json + exercises/
├── TESTS.md                  # Comprehensive test documentation
└── update-tests.sh           # Script to sync version details in TESTS.md
```
